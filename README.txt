BG Service - BOOTSTRAP 5 WEBSITE

Structure:
- 17 HTML pages
- css/style.css (all custom styling)
- js/main.js (small form/year enhancements)
- assets/images (local SVG backgrounds)

Responsive behavior is primarily handled by Bootstrap 5 grid, navbar and utilities.
Forms are frontend demos and can be connected to PHP, Formspree, SMTP or another backend.

The page architecture and subject matter were built to closely follow the supplied law-firm reference while using original branding and paraphrased text rather than reproducing the source website verbatim.
